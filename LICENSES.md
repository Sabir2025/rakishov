# Материалы и лицензии

- `assets/images/author.webp`: фотография из предоставленного пользователем архива. Используется в его персональном портфолио; права сохраняются у исходного правообладателя.
- `assets/images/*.svg`: оригинальные векторные иллюстрации, созданные для этого проекта. Превью проектов являются концепциями, а не скриншотами реальных клиентских сервисов.
- `assets/fonts/manrope.ttf`: Manrope, SIL Open Font License 1.1. Источник: https://github.com/google/fonts/tree/main/ofl/manrope. Полный текст лицензии — `assets/fonts/OFL-Manrope.txt`.
- `assets/fonts/kazakh.ttf`: подмножество Noto Sans для дополнительных казахских символов, SIL Open Font License 1.1. Источник: https://github.com/google/fonts/tree/main/ofl/notosans. Лицензия — `assets/fonts/OFL-NotoSans.txt`. Используется как дополнение для символов, отсутствующих в Manrope.
- Функциональная часть сайта написана для проекта. Внешних фотографий, платных UI-наборов или заимствованных клиентских кейсов нет.
- Cloudflare Turnstile — внешний сервис проверки формы, подключается только при заданной конфигурации.
- Инструменты проверки `@electric-sql/pglite` (Apache-2.0) и `linkedom` (ISC) устанавливаются только для тестов; они не входят в публичную сборку.

- `assets/logo.svg` и `assets/favicon.svg`: предоставленные пользователем файлы, логотип перекрашен в чёрный, фавикон сохранён без изменений.

- `assets/fonts/noto-sans.ttf`: Noto Sans (SIL OFL), подмножество латиницы и кириллицы для полного набора казахских букв. Лицензия: `assets/fonts/OFL-NotoSans.txt`.
