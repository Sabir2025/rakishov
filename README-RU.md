# Публичный сайт Sabir Rakishov

Это отдельный публичный сайт: главная, кейсы, форма заявки и три языка. KZ — по умолчанию. Страниц кабинета и ссылки на него здесь нет. Ссылка настроек статистики из подвала удалена. WhatsApp и телефон заменены на +7 702 295 00 40.

## Публикация

1. Заполните `js/settings.js` по инструкции `CONNECTION-RU.md`.
2. Перенесите обновлённые настройки в `dist/`: `python3 scripts/package_site.py`.
3. Загрузите СОДЕРЖИМОЕ `dist/` на публичный хостинг. Остальные файлы — исходники и инструменты разработки.
4. Базу и функцию подключите один раз по инструкции из отдельного архива аналитики.

Сам сайт работает на HTML, CSS и JavaScript. Файлы для размещения уже собраны. React и сервер Node.js на хостинге не нужны.

При смене адреса сайта измените `ORIGIN` в `scripts/build.py`, затем пересоберите проект. Это обновляет canonical и sitemap. Относительные пути поддерживают подпапку, например `/rakishov/`.

## Редактирование и сборка

- `content/translations.json` — тексты на трёх языках.
- `scripts/build.py` — структура страниц и макеты кейсов.
- `css/site.css` — оформление.
- `js/animation.js` — сетка с реакцией на курсор.
- `js/form.js` — форма, `js/api.js` — только публичный приём данных.
- `js/settings.js` — публичные настройки. Приватных ключей здесь быть не должно.

Для пересборки нужны Node.js 24+ и Python 3:

```sh
npm ci
npm run build
npm test
```

Для просмотра можно открыть index.html после полной распаковки. Для проверки отправки используйте HTTP-сервер или размещение по HTTPS; `file://` не входит в разрешённые origins.

Изображения кейсов — обозначенные авторские концепции. См. LICENSES.md.

Проверены ссылки, JS, переключение языков и запуск интерфейса на уровне DOM. Визуальная проверка браузером и реальное подключение Supabase не выполнены.
